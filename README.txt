# FIgura - Cognifyz Front-End Intern Project

## Project Documentation

### File Structure
- `src/`
  - Main application source files.
- `public/`
  - Static files such as HTML and images.
- `components/`
  - React components used throughout the application.
- `styles/`
  - CSS files and styling resources.

### Key Features
- User authentication and authorization.
- Responsive design for various devices.
- Integration with back-end APIs for dynamic content.
- State management using Redux.

### Implementation Details
- **Framework:** React.js
- **State Management:** Redux
- **Routing:** React Router for navigation.
- **Styling:** CSS modules for component-level styles.

### Usage
To set up the project locally:
1. Clone the repository.
2. Navigate to the project directory.
3. Run `npm install` to install dependencies.
4. Start the application with `npm start`.  

For deployment, use `npm run build`.
